# Akadálymentesség – WCAG 2.2 AA ellenőrzőlista

A cél a WCAG 2.2 AA megfelelés. Az automata ellenőrzés (`e2e/a11y.spec.ts`, axe-core, világos és sötét témában) nem találhat serious vagy critical hibát; a manuális pontokat kiadás előtt végigjárjuk.

## Észlelhetőség

- [x] Minden felhasználói szöveg magyar, a dokumentum nyelve `lang="hu"`.
- [x] A térkép cellái nem csak színnel különböznek: a fal sraffozott, az arany ikont kap, a robot irányított nyíl kör alakú jelölőben, a felderítetlen terület eltérő mintázatú (1.4.1).
- [x] Minden cellának szöveges címkéje van: „3. sor, 5. oszlop: arany”, a robotnál az iránnyal (1.1.1).
- [x] Szövegkontraszt legalább 4.5:1 (nagy szövegnél 3:1) mindkét témában; a színek tokenekben, `oklch`-ban (1.4.3, 1.4.11).
- [x] A díszítő ikonok és a mini térképek `aria-hidden` (1.1.1).
- [ ] 200%-os nagyítás és 320 px szélesség: vízszintes görgetés nélkül használható (1.4.4, 1.4.10) – kézi ellenőrzés hátra.

## Kezelhetőség

- [x] Ugrólink a tartalomra minden oldalon (2.4.1).
- [x] Minden funkció elérhető billentyűzettel: React Aria komponensek, natív gombok és linkek (2.1.1); e2e teszt: `e2e/keyboard.spec.ts`.
- [x] A térképrács roving tabindexszel egy tabulátor-megálló, a cellák között nyilakkal, Home/End és Ctrl+Home/End billentyűvel lehet mozogni (2.1.1, APG data grid).
- [x] A kódszerkesztő nem csapda: Esc, majd Tab kilép belőle; ezt a szerkesztő alatti súgó is jelzi (2.1.2).
- [x] Látható fókuszgyűrű minden interaktív elemen (`:focus-visible`, 3 px) (2.4.7, 2.4.11).
- [x] `prefers-reduced-motion` esetén az animációk és átmenetek kikapcsolnak (2.3.3).
- [x] A lejátszás sebessége állítható és szüneteltethető (2.2.2).
- [ ] Az érintési célok legalább 24×24 px (2.5.8) – a 15×15-ös térkép celláinak mérete kis képernyőn ellenőrizendő.

## Érthetőség

- [x] A hibaüzenetek magyarul, a hibás sor számával; a szintaktikai és futásidejű hibák mellett súgó szöveg (3.3.1, 3.3.3).
- [x] Az űrlapmezőknek látható címkéjük és leírásuk van (3.3.2).
- [x] A gombok akadálymentes neve tartalmazza a látható szöveget (2.5.3), például „Felhasználói menü: demo1”.
- [x] Egységes navigáció minden védett oldalon (3.2.3).

## Robusztusság

- [x] Szemantikus HTML: `header`, `nav`, `main`, `section`, valódi `table` a ranglistához és az adminhoz, `table role="grid"` a térképhez (4.1.2).
- [x] Állapotüzenetek: a lejátszás összefoglalója `aria-live="polite"` régióban, fojtva (legfeljebb 1,5 másodpercenként), a toastok React Aria régióban (4.1.3).
- [x] Az aktuálisan futó sor a szerkesztőben `aria-current="step"` jelölést kap.

## Ismert kivétel

A React Aria saját, globális élő bejelentője átmenetileg egy üres `role="img"` elemet tesz a DOM-ba, amire az axe `role-img-alt` hibát jelez. Ez a könyvtár belső mechanizmusa (a bejelentés után eltűnik), ezért az `e2e/a11y.spec.ts` ezt az egy elemet (`[role="log"][aria-live="assertive"] > [role="img"]`) kizárja az ellenőrzésből.
